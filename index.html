MSc dissertation · University of Bristol

Length generalisation in Transformer sequence models

A configuration-driven PyTorch pipeline on AWS GPU infrastructure running 45 Transformer baselines across 3 algorithmic tasks, 5 positional encodings and 3 random seeds, evaluated at sequence lengths up to 1,024.

  • Built an evidence-based failure taxonomy separating training underfitting, seed instability, immediate extrapolation collapse and position-dependent error patterns
  • Established a multi-seed baseline-eligibility framework, identifying 5 of 15 configurations with 92–100% mean training-length exact-match accuracy; all five reached 0% at the first tested unseen length
  • Diagnosed task-specific failures with position-wise error profiles, attention statistics, carry-condition and dependency-distance analysis rather than aggregate accuracy alone
  • Tested mixed-length training, curriculum learning and randomised padding, separating genuine underfitting from interventions that preserved training performance without improving unseen-length exact match

Cloud engineering · AWS

Elastic event-driven data pipeline

Deployed an event-driven processing architecture using S3, SQS, Ubuntu EC2 workers and DynamoDB, with least-privilege IAM and queue-depth Auto Scaling through CloudWatch. A 120-file burst test scaled the fleet from one worker to two, processed the full workload without data loss and returned to minimum capacity once the queue drained.

Astronomical machine learning · Ongoing

Robust anomaly detection under instrument shift

Developing a reproducible Kepler and TESS light-curve pipeline — quality-flag filtering, missing-data handling, detrending and normalisation — with Isolation Forest anomaly scoring and cross-quarter, cross-instrument evaluation that separates rare temporal behaviour from detector-specific distribution shift.
